# Rank-only workbook snapshot

Date: 2026-10-09.

full-chart-reference-google-ranks.json is a deliberate minimal projection of the local, excluded google-sheets-live-2026-10-09.json capture. It contains only 354 title cells used by catalog assertions, their source grade cells, sheet names/gids, original row/column positions and strikeout markers. All other value slots are empty placeholders. They are not evidence that the original cells were blank. The JSON records the original capture SHA-256.

No salary, personnel, named pay-adjustment or unrelated workbook column is copied. The source sheets are General Pay Scale (gid 0), IRAF Pay Scale (gid 11), and Special Pay Scale (Revamping) (gid 9). Source sheet names are retained as provenance, not evidence that financial data is included.

The builder reads this included snapshot directly. A repository clone requires no private workbook capture or official export directory to reproduce the catalog. The original live capture remains locally excluded; verification compared every included title and grade against it and checked corresponding strikeout markers. Catalog assertions keep original workbook URLs and cell addresses. Shared upper-title assertions remain disputed evidence, including struck-out Grand Vizier, rather than new rank records.

Verification: 354 included title cells matched their original source coordinates/text/strikeout state; 210 branch records, 69 military records, 66 blank cells, seven shared titles and 178 candidate patterns regenerated. No source precedence or creative approval was inferred.
