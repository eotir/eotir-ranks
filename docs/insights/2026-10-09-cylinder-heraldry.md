# Cylinder engraving identity and entitlement
Date: 2026-10-09
Project: Imperial Republic ranks
Tags: cylinders, heraldry, approval, reference-assets, gallery

## Context

Ryan accepted all three v2 cylinder base directions and requested engraved Imperial Republic Standard or Imperial Republic Shield versions in silver and gold, plus the supplied Claude Design gallery presentation. Twelve v3 studies are rendering; this insight records the verified input constraints, not completed render results.

## What we tried

1. Read current music/videos/refs/HERALDRY-USAGE.md.
2. Read anchor-imperial-republic-standard--silver.md, anchor-imperial-republic-standard--gold.md, anchor-imperial-republic-shield--silver.md and anchor-imperial-republic-shield--gold.md.
3. Compared their approval, identity, wearer scope and compositing descriptions with the engraving request.

## What happened

All four source marks are LOCKED. The Standard is the interior Shield bird with the border removed; it is not Stratus. The Shield is assigned to defense/military/security/police/intelligence; the Standard to civilian/government/patriotic use. Gold belongs to High Command within each group, with no exhaustive membership or rank mapping supplied.

The Standard masters and clean Shield masters are opaque charcoal-background references. Shield transparent support parents have unresolved alpha fringes. The Silver Shield description includes silver/cyan appearance, while the wearer ruling distinguishes silver/gold from cyan/violet production branding. Ryan now requests neutral silver engraved metal; using that material does not redefine the approved mark silhouette.

## Root cause / why

A locked reference image establishes approved identity and its recorded use. Its scene background and lighting are not automatically part of a new engraved device. Likewise, acceptance of a base cylinder design does not approve a subsequent mark application or resolve rank/class/count entitlement.

## Takeaway

Preserve mark identity and document each new engraved version separately; use neutral silver or gold metal without copying reference backdrops. Keep branch entitlement and High Command membership separate from visual studies, and use Ryan's supplied Claude Design gallery for review.
